# Meeting Notes Homebrew Cask

This tap distributes the macOS desktop app [Meeting Notes](https://github.com/f71uday/meeting-notes).

After the first signed and notarized release, install it with:

```sh
brew install --cask f71uday/meeting-notes/meeting-notes
```

The release workflow in `f71uday/meeting-notes` maintains `Casks/meeting-notes.rb` and the release checksums. Do not edit the generated cask by hand.
